How it works

Goodreads shut down its public API in 2020, but every public shelf still has an RSS feed with the reader's star ratings, the Goodreads average, page count, year and description. A GitHub Action (.github/workflows/goodreads-sync.yml) pulls the read shelf of everyone in book-club/data/readers.json every morning (here's Adam's). It tags each book's themes from its description and commits book-club/data/goodreads-<id>.json, which this page reads. The six contenders and their hand-scored discussion notes live in book-club/data/candidates.json.
